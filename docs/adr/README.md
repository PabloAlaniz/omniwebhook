# Decisiones de arquitectura

Cada decisión de diseño que condiciona al resto queda escrita acá, en un archivo numerado. Una
decisión no se edita para cambiarla: se agrega otra que la reemplaza y se actualiza el estado de la
anterior.

| N.º | Decisión | Estado |
|---|---|---|
| [0001](0001-arquitectura-en-capas.md) | Arquitectura en capas con dependencias hacia adentro | Aceptada |
| [0002](0002-formato-de-salida-estandar.md) | Formato de salida estándar, con la librería de referencia detrás de un puerto | Aceptada |
