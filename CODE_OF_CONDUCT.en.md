# Code of conduct

> **Translation.** This is a translation of the [Spanish original](CODE_OF_CONDUCT.md). If the two disagree, the Spanish text wins.

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies to all project spaces: issues, pull requests, discussions and code reviews.

## In short

- The code and the ideas are what is discussed, not the people.
- Good intent is assumed, and the reason behind an objection is explained.
- There is no place for harassment, derogatory comments or publishing another person's private
  information.

## How to report

If you saw or received inappropriate treatment, write privately to the project maintainer, using
the contact details on their [GitHub profile](https://github.com/PabloAlaniz). The report is
confidential and will get a response.

The project maintainer can edit or delete comments, commits and issues that do not comply with
this code, and suspend, temporarily or permanently, anyone who breaches it.
