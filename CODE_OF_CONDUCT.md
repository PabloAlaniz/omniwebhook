# Código de conducta

Este proyecto adopta el
[Contributor Covenant, versión 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).
Vale para todos los espacios del proyecto: issues, pull requests, discusiones y revisiones de
código.

## En resumen

- Se discute el código y las ideas, no a las personas.
- Se asume buena intención y se explica el porqué de una objeción.
- No hay lugar para el acoso, los comentarios despectivos ni la publicación de datos privados de
  otra persona.

## Cómo reportar

Si viste o recibiste un trato que no corresponde, escribile en privado a quien mantiene el
proyecto, por el medio de contacto de su [perfil de GitHub](https://github.com/PabloAlaniz). El
reporte es confidencial y va a tener respuesta.

Quien mantiene el proyecto puede editar o borrar comentarios, commits e issues que no cumplan con
este código, y suspender de forma temporal o definitiva a quien lo incumpla.
